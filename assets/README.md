# Lennon mascot

`lennon.svg` is the project mascot, drawn from the owner-provided photographs.

Keep the features that make him recognizable:

- A lean, black, wire-haired podenco with a narrow face and shaggy muzzle.
- One tall, outward-pointing ear and one ear folded forward.
- Silver-grey eyebrows, cheeks, whiskers, beard, and a small pale chest patch.
- Dark brown eyes with a soft, attentive, slightly melancholy expression.
- A broad black nose and an uneven, scruffy coat.

The illustration uses charcoal, muted sage-grey, and warm silver on an ivory
background. Keep it as editable SVG with an accessible title and description.
The cream tile and monospaced wordmark match Lennon's existing project identity.
